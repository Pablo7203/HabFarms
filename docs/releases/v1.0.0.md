## Backup status

The production project uses the Supabase Free plan. A pre-launch public-schema logical backup was made on 2026-08-23 in the Git-ignored local directory `backups/2026-08-23-prelaunch/`:

- `schema.sql` — 198,356 bytes
- `data.sql` — 11,694 bytes

The repository migrations are the authoritative schema history. The logical data export must be kept in protected storage and restored into an isolated project for validation. Supabase Auth identities and credentials are not included in the public-schema dump and require separate platform-supported recovery or verified-email account recreation. Managed backup retention and PITR remain plan-dependent.
